# 관리자 기능 대조

기준은 최신 통합 브랜치다. PR 21·22·23을 각각 foundation에 넣지 않는다. foundation 병합은 Development API를 자동 배포하고 `npm run db:migrate:deploy`로 마이그레이션을 적용한다.

## 정책

| 요구 | 구현 | 검증 |
| --- | --- | --- |
| 새 모임 30일 체험, 기존 모임 소급 없음 | 생성 트랜잭션에서만 `TRIAL` | API |
| 같은 회원의 다른 모임도 각각 체험 | 모임 행당 청구 하나 | API |
| 삭제 후 재생성 체험 반복 | 이름·휴대폰으로 추정하지 않음. 미결 | 자동 구분 없음 |
| 회원 수 제한 없음 | 인원 한도 검사 없음 | 코드 확인 |
| 만료와 정지는 독립 | `suspendedAt`은 갱신으로 안 풀림. 기간은 이용권 시각 | API |
| 요청 시각에 새 행사·장부·회비·업로드·확정·재개 차단 | `assertGatheringWritable` | API. 읽기·다운로드는 유지 |
| 유료 갱신 잔여 보존 | `formalTermExpiry` = max(지금, 현재 만료)+1년. 시작·종료를 직접 주면 그 구간 | API |
| 미래 시작 이용권 | 현재 구간이 있으면 그 행을 보여 줌 | API 조회 |
| 용량은 원본 사진·영상·영수증과 살아 있는 예약 합 | 별도 썸네일 파일은 저장하지 않음. 화면 썸네일은 원본 URL | 코드 확인 |
| 용량을 사용량 아래로 줄여도 파일 유지 | 행을 지우지 않음. 새 예약만 거절 | API |
| 예약과 확정 크기 불일치 | `SIZE_MISMATCH`로 확정 거절 | 기존 미디어 테스트 |
| 동시 예약 | 모임 행 잠금 후 합계 검사 | 기존 미디어 테스트 |
| 회원 제한 | 회장도 제한된다. 회장 역할 행과 인계·장부 행은 지우지 않는다. 제한된 계정의 모임 조회와 쓰기는 거절된다. 관리 화면에서는 그 회원과 이력을 볼 수 있다 | API |
| 장부·인계 행 삭제 없음 | 제한 API가 그 테이블을 지우지 않음 | API |
| 입금과 이용권 분리 | 확인만으로 기간이 늘지 않음. 6만 원이 아니면 자동 연결 없음. 예외 연결은 슈퍼관리자만 | API |
| 무상은 입금과 별도 | `COMPLIMENTARY` | API |
| 연락처 | `CONTACT_READ`일 때만. 조회 감사 | API |
| 담당 관리자 범위 | 다른 모임 404 | API |
| 회원 토큰으로 관리 API | 401 | API |
| TOTP 비밀 | 암호문 저장. 등록 화면 한 번. 다른 등록 토큰은 확인 시 무효 | API |
| 비밀번호 5회·세션 폐기·CSRF | 잠금, 로그아웃, 비밀번호 변경, `/me`가 CSRF를 바꿈 | API |
| 마지막 슈퍼관리자 | 읽기 커밋 격리에서 슈퍼관리자 행을 잠근 뒤 검사 | 코드. 공유 테스트 DB에 다른 슈퍼관리자가 있어 두 계정만의 동시 비활성은 분리하지 못함 |
| 감사 로그 | 추가만. 수정 API 없음 | 코드 확인 |
| 회원수첩 회귀 | 기존 테스트 | API |

## 브라우저 22단계

로컬 API와 빌드된 관리 화면에 붙여 자동으로 연 것은 로그인 화면이 320·1280 너비에서 보이는지다. 아래는 아직 그 브라우저 자동 시나리오로 확인하지 않았다.

1. 가입
2. 모임 만들기
3. 30일 체험 표시
4. 관리 목록에 즉시 표시
5. 생성자·회장 연락처 복사와 전화·문자 링크
6. 정식 1년 승인
7. 사진·영상 업로드
8. 50GB 한도
9. 100GB로 증가
10. 용량 축소 후 기존 파일 유지
11. 정지 후 새 입력·업로드 거절
12. 기존 자료 열람
13. 정지 해제
14. 체험 만료
15. 정식 만료
16. 인계로 현재 회장 변경
17. 최초 생성자 유지
18. 감사 이력 화면
19. 일반 회원 토큰 거부
20. 무상 기간과 입금 불일치
21. 회원 제한과 인계 조회
22. 로그아웃·비밀번호 변경·세션 만료

1–22의 서버 동작 중 일부는 API 테스트에 있다. 실기기와 Development 데이터에는 쓰지 않았다.
