# 제품 범위 — 모바일 전자 회원수첩

## 서비스 목적

종이 회원수첩을 모바일로 재구성한 SaaS다. 여러 지역 로컬 청년회의소(JC)가 **하나의 공통 앱**을 사용하되, 각 로컬은 **독립적으로** 운영한다.

예시 로컬:

- 서울광진청년회의소
- 서울강남청년회의소
- 부산동래청년회의소

## 모바일 전용

- 기준 폭 390px (360–430 대응)
- PC 화면·PC 관리자·데스크톱 테이블 UI는 범위 밖이다.

## 다중 로컬 · 데이터 분리

회원은 소속 로컬의 다음 데이터만 조회한다.

- 회원, 임원, 역대회장, 특우회
- 일정, 공지, 정관·규정, 로컬 설정

**지구(District)** 는 가입 시 로컬을 찾기 위한 분류일 뿐이다.

제외:

- 지구 통합 관리자
- 지구 전체 회원 조회
- 로컬 간 데이터 조회

## 사용자 역할 (1차)

| 역할 | 설명 |
|------|------|
| MEMBER | 일반 회원 |
| LOCAL_ADMIN | 로컬 관리자 |
| LOCAL_OWNER | 최고관리자 |

## 1차 MVP (본 foundation 단계)

- 프로젝트 구조 · 디자인 토큰
- DB 기본 스키마 · Seed
- 인증 (로그인/갱신/로그아웃/me)
- 로컬 격리 미들웨어
- 회원 목록·상세 API
- 앱 스플래시·로그인·홈·회원목록·상세·내정보·하단탭
- 교차 로컬 접근 차단 테스트
