# 비회원 업로드 링크

회장이나 총무가 행사 또는 자유 폴더에 업로드 링크를 만든다. 받는 사람은 앱 없이 브라우저에서 사진·영상만 올린다. 승인은 없고, 확인이 끝나면 앨범에 바로 보인다. 명부·재무·기존 파일은 열리지 않는다.

링크는 7일 뒤 만료된다. 회장·총무가 취소, 일시정지, 다시 열기를 할 수 있다. 용량은 모임 50GB에 포함된다.

브라우저가 R2로 직접 PUT하므로, 버킷 CORS에 `PUT`과 헤더 `Content-Type`, `Content-Length`가 필요하다.

실기기: Android와 iOS에서 링크를 공유하고, 다른 폰 브라우저로 사진 한 장을 올린 뒤 모임 앨범에 바로 보이는지 확인한다.
