# DECISIONS

## 확정 (사용자 지시 2026-11-29 총괄 지시문 §19 및 이전 지시)
- 앱 이름: JCI KOREA. 내 로컬과 내 모임 통합, 서비스별 권한 독립
- 로컬 가입 요청은 수동(로컬 선택 ≠ 가입 요청). 승인된 같은 로컬 회원만 명부 열람
- 현역(YB)·특우(OB) 공통 열람 권한(메뉴 분리 없음, 분류·필터만)
- 종이 수첩 형태 유지, 확정 Figma(`SSdT1N1zyaaOjFBteoksYo`) 적용, 증명사진 3:4, 사진 없는 회원도 자리 유지(AI·임의 사진 금지)
- 앱 미사용 회원 등록, YB→OB 수동 전환(만 45세 자동 전환 금지, 되돌리기 가능)
- 회원 상세 개인정보 직접 수정, 정확한 주소·우편 수령지, 배우자·자녀 정보(해당자만 선택 입력)
- 회사·사업 소개, 도움 줄/받을 분야
- 연도별 회장단(직전회장 포함), 기본 직책 + 자유 추가 직책, 사무국장 중심 실무, 직책 추가·수정·배정, 연도별 이력 영구 보존
- 차기 회장에게 관리 권한 인계, 직책 ≠ 권한(권한은 별도 부여·기록)
- PDF 정관의 검색 가능한 전자화(검수 후 게시, 2016 정관을 현행으로 표시 금지)
- 기존 모임 기능 유지(회계연도·사진·회비·용량·이용권·권한 정책 무변경)
- 운영: Production·main·운영 DB 변경, 유료 API는 별도 승인. ONE FC·기존 회원수첩 운영 서비스 접촉 금지
- 용어: "집행부" 대신 "회장단"·"임원"
- 주민등록번호 수집 금지(기존 지시)

## 미확정 — 설정 가능 구조로 두고 적용 시점에 질문
| ID | 질문 | 임시 설계 |
|---|---|---|
| D-OPEN-1 | 사무국장이 임원 명부를 확정할 수 있나, 회장 승인이 필요한가 | 로컬 설정 `rosterConfirmRequires = PRESIDENT`(기본) / `SECRETARY_GENERAL` |
| D-OPEN-2 | 특우회장·특우회 관리자의 독립 인계 범위 | 조직 단위(현역/특우) 분리 데이터 구조만, 권한 적용은 보류 |
| D-OPEN-3 | 로컬 연도별 인계 효력일 기본값 | 로컬 설정값(미설정 시 관리자 지정 필수), 모임 회계연도 규칙 미적용 |
| D-OPEN-4 | 회원 상세정보 필수/선택 범위 | 이름만 필수, 나머지 선택(설정으로 필수화 가능) |
| D-OPEN-5 | 문자 업체·실제 발송 정책 | provider 인터페이스 + mock, 실발송 비활성 |
| D-OPEN-6 | 로그인 "아이디": 현재 운영은 휴대폰 번호가 로그인 ID. 별도 아이디를 추가할지 | 현행 유지(휴대폰=ID) 제안, 결정 전 변경 없음 |
| D-OPEN-7 | 회원가입 휴대폰 SMS 인증(유료) 도입 시점·업체 | 미도입 유지, 로컬 승인 시 관리자 본인 확인으로 대체 |

| D-OPEN-10 | 로컬 "서비스 활성화"는 누가 켜나(본사 관리자 웹 / 로컬 신청) | 본사 관리자 웹 토글 |
| D-OPEN-11 | 최초 로컬 관리자(회장/사무국장) 지정 방법 | 본사 관리자 웹에서 지정 + 감사로그 |
