# 모임 앱 화면 확인 (Android / iPhone)

미리보기 빌드 또는 개발 빌드로 확인합니다. 운영 배포는 하지 않습니다.

- 모임 화면 탭이 홈, 회원, 일정, 사진, 재무 순서로 아이콘과 글자가 함께 보인다. 선택된 탭은 남색 배경에 흰 글씨다. 긴 모임 이름은 잘리지 않고 줄바꿈된다.
- 홈에 회계연도와 협의회장, 활동 회원 수, 다음 행사, 최근 행사, 최근 사진, 재무 요약이 카드로 보인다. 이용권 기간은 홈의 중심 문구가 아니다.
- 협의회장, 총무, 회원 관리 권한이 있으면 홈에 관리 버튼이 있다. 관리에서 집행부, 초대 승인, 초대 링크 발급·복사·공유·폐기, 가입 승인을 처리한다.
- 초대 링크를 만들면 `jcikorea://invite/...` 주소가 한 번 전체로 보인다. 링크 복사는 클립보드에 넣고, 공유는 기기 공유 시트를 연다. 카카오가 설치되어 있으면 그 시트에서 고른다.
- 발급 목록에 만료, 사용 횟수, 폐기가 보인다. 폐기한 링크로는 참여할 수 없다.
- 역할은 협의회장, 총무, 재무, 집행부, 일반 회원으로 보인다. `PRESIDENT` 같은 영문 코드는 화면에 나오지 않는다.
- 화면 너비 360 전후와 더 넓은 폰에서 탭 글자와 카드가 겹치지 않는지 본다.
