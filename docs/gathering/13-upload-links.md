# 비회원 업로드 링크

회장이나 총무가 행사 또는 자유 폴더에 업로드 링크를 만든다. 받는 사람은 앱 없이 브라우저에서 그 행사(또는 폴더)의 사진·영상을 올리고, 이미 올라간 사진·영상도 같은 앨범 화면에서 볼 수 있다. 승인은 없고, 확인이 끝나면 앨범에 바로 보인다. 회원 명부와 재무, 다른 행사·폴더·모임은 열리지 않는다.

링크는 7일 뒤 만료된다. 회장·총무가 취소, 일시정지, 다시 열기를 할 수 있다. 용량은 모임 50GB에 포함된다.

브라우저는 업로드를 R2로 직접 PUT하고, 보기와 다운로드는 짧은 유효기간(10분)의 서명 GET URL을 사용한다. 버킷 전체를 공개하지 않는다. 브라우저 다운로드는 서명 GET URL의 응답을 파일로 저장한다. 버킷 CORS에 `GET`, `PUT`과 헤더 `Content-Type`, `Content-Length`가 필요하다.

실기기: Android와 iOS에서 링크를 공유하고, 카카오톡·삼성 인터넷·Chrome·Safari로 사진 한 장을 올린 뒤 같은 링크와 모임 앨범에 바로 보이는지 확인한다.
