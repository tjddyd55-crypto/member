## 확정 (사용자 지시 2026-11-29 총괄 지시문 §19 및 이전 지시)
- 앱 이름: JCI KOREA. 내 로컬과 내 모임 통합, 서비스별 권한 독립
- 로컬 가입 요청은 수동(로컬 선택 ≠ 가입 요청). 승인된 같은 로컬 회원만 명부 열람
- 현역(YB)·특우(OB) 공통 열람 권한(메뉴 분리 없음, 분류·필터만)
- 종이 수첩 형태 유지, 확정 Figma(`SSdT1N1zyaaOjFBteoksYo`) 적용, 증명사진 3:4, 사진 없는 회원도 자리 유지(AI·임의 사진 금지)
- 앱 미사용 회원 등록, YB→OB 수동 전환(만 45세 자동 전환 금지, 되돌리기 가능)
- 회원 상세 개인정보 직접 수정, 정확한 주소·우편 수령지, 배우자·자녀 정보(해당자만 선택 입력)
- 회사·사업 소개, 도움 줄/받을 분야
- 연도별 회장단(직전회장 포함), 기본 직책 + 자유 추가 직책, 사무국장 중심 실무, 직책 추가·수정·배정, 연도별 이력 영구 보존
- 차기 회장에게 관리 권한 인계, 직책 ≠ 권한(권한은 별도 부여·기록)
- PDF 정관의 검색 가능한 전자화(검수 후 게시, 2016 정관을 현행으로 표시 금지)
- 기존 모임 기능 유지(회계연도·사진·회비·용량·이용권·권한 정책 무변경)
- 운영: Production·main·운영 DB 변경, 유료 API는 별도 승인. ONE FC·기존 회원수첩 운영 서비스 접촉 금지
- 용어: "집행부" 대신 "회장단"·"임원"
- 주민등록번호 수집 금지(기존 지시)

## 확정 — 2차 확정 (사용자 2026-11-29 t122, 이전 D-OPEN-6~12 해소)
| ID | 결정 |
|---|---|
| D-6 (구 OPEN-8) | `apps/gathering-mobile`이 통합 앱. 여기에 "내 로컬" 추가. `apps/mobile`은 참고용으로 유지, **삭제·수정 금지** |
| D-7 (구 OPEN-6) | 모임 앱의 기존 로그인 계정 공통 사용(휴대폰 번호=로그인 ID 유지). 로컬 데이터는 **매 요청마다 서버가 해당 로컬 ACTIVE 멤버십 + 권한을 검사** |
| D-8 (구 OPEN-7) | 당분간 기존 로그인 방식 유지. **휴대폰 본인 확인은 최종 요구사항에서 제외하지 않음**(미구현 상태로 기록, 유료 문자 서비스는 별도 승인 후 연동). 인증 전: 전화번호만으로 기존 회원 자동 연결 금지, 전화번호만으로 관리자 권한 부여 금지. 로컬 가입은 관리자 확인·승인 필수 |
| D-9 (구 OPEN-9) | YB/OB = **고정 기본 분류**, 로컬별 회원 소속정보(로컬 멤버십/회원 프로필 단위)에 연결. YB→OB는 관리자 수동, 이력 기록·되돌리기 가능. 기존 `MembershipCategory`는 부가 분류로만 |
| D-10 (구 OPEN-10/11) | 본사 최고관리자 웹에서 **로컬 서비스 활성화** + **최초 로컬 관리자 지정**. 이후 로컬 회장이 사무국장 지정·필요 권한 부여·매년 차기 회장에게 인계. **서비스 활성화 상태(신규 필드)와 로컬 자체 활성 상태(`Local.isActive`)는 별개** |
| D-11 (구 OPEN-12) | 주소: **무료 도로명주소 검색**(예: 행정안전부 juso.go.kr)을 우선 사용. 우편번호·도로명주소·상세주소·**우편물 수신지·선물 수신지**를 각각 관리. 유료 외부 서비스는 승인 없이 사용 금지 |
| D-12 | 과거 수첩 개인정보를 공개 저장소·로그에 올리지 않고, 검증 없이 현재 운영 데이터로 등록하지 않음. 단계별 진행 상황은 GitHub(`docs/agent`)에 기록, 예약 작업 중복 실행 방지 |
| D-13 | Production 배포·운영 DB 변경은 별도 승인 전까지 진행하지 않음 |
