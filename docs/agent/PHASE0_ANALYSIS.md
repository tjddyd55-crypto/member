## 5. 인증·권한 구조 — 충돌 지점
- 운영 사용자 계정은 **모임 인증**(`/api/gathering/auth/*`, 휴대폰+비밀번호, `GatheringSession`)으로 만들어졌다.
- foundation 인증(`/api/auth/*`, `RefreshSession`)은 **토큰이 하나의 LocalMembership에 묶임**(로컬 단위 세션). 통합 앱과 맞지 않음.
- 제안: 통합 앱은 모임 세션을 유일한 로그인으로 사용하고, 로컬 API는 요청마다 `(userId, localId)` ACTIVE 멤버십을 DB에서 검증하는 새 guard(`requireLocalMember(localId)`, `requireLocalPermission(perm)`)를 둔다. foundation 라우트는 회귀 테스트(`member-book-regression.test.ts`) 유지를 위해 제거하지 않고 그대로 둔다.
- 현재 회원가입은 **아이디 없이 휴대폰 번호가 로그인 ID**이며 SMS 인증이 없다. 지시문의 "아이디 + 휴대폰 인증"과 다름 → **확정(D-7, D-8)**: 기존 로그인 유지, 본인 확인은 최종 요구사항(유료 문자 승인 후), 인증 전 자동 연결·번호만으로 관리자 부여 금지.

### 10.1 파일 매핑

### 10.2 회원명단(현역) 레이아웃·필드
- 한 쪽에 4명 세로 배열. 각 항목 = 좌측 **증명사진(세로형, 약 3:4)** + 사진 아래 **JC 직책 캡션**(예: 회장·총무분과위원장·운영위원), 우측에 정보 블록.
- 필드: 성명(한자 병기) · 배우자 이름 · 휴대폰 · 생년월일(양/음 표기) 및 둘째 날짜(배우자 생일 또는 결혼기념일 추정 — 확인 필요) · 자녀 이름들 · 회사명/직위 · 직장 주소+TEL+FAX · 자택 주소(우편번호 포함)+TEL+FAX · JC 가입일/회원번호 · 이메일(·홈페이지).
- 특우회 명단은 현역과 같은 구성(회장 직함 캡션 포함: 대수 + 직책), 사진 있음, 직장/자택 주소·전화·팩스·이메일.
- 사진 없는 회원은 해당 칸이 비어 있음 → 앱에서도 빈 자리 유지(확정 사항과 일치).

### 10.3 역대회장 레이아웃
- **현역**: 한 쪽에 5명 세로. 좌측 사진 + 사진 아래 `N대회장`·성명·(재임 연도). 우측 정렬 명단 `직책 : 성명`: 직전회장, 상임부회장, 내무부회장, 외무부회장, 감사(2), 사무국장. 초기 대수는 직전회장 항목이 없음. 8쪽(약 40명 규모).
- **특우**: 한 쪽에 4열×6행(24명) 격자. 사진 아래 `N대 성명`과 연도. 연임은 `3,4대`, `13,14대`, `24,25대`처럼 대수 병기 + 연도 범위(`1990-91`, `2011~12`). Figma 04와 동일 구조.
- 연락처 별쇄(역대회장 4쪽): 성명, 자택전화, 직장전화, 직장주소 등 표.

### 10.4 연도별 회장단·임원 기록
- 2016 회장단: 회장·직전회장·상임부회장·내무부회장·외무부회장·감사 2 (도식 배치). 사무국장은 별도(기구표에서 사무국 아래).
- 기구표(조직도): 회장 → 상임부회장 → 내무·외무부회장 → 분과위원회(총무·중점사업·홍보활동·조직관리·대외활동·국제활동·회원확충 등), 사무국(사무국장/사무차장), 운영협의회, 감사. 회전된 이미지라 텍스트 추출 불가.
- 분과위원회 구성표: 분과명 / 위원장 / 부위원장 / 위원(복수), **미정(공석) 표기 존재**.
- 임원현황표: NO / 직위 / 성명 / 생년월일·JC가입일 / 직장·직위. 직위에는 회장단·사무국장·법제상임이사·재정상임이사·연수상임이사·분과위원장 등 상임이사·위원장이 섞여 있고 **미정** 칸이 있음 → 공석 허용, 직책 목록이 해마다 가변.
- 특우회 2016 회장단 및 임원: 회장·직전회장·부회장 2·감사 2 + 사무국장·총무/재정/경조/기획/현역지원/회원관리/국제관계 위원장·산악회장 등 임의 직책 + 운영협의회(위원장·위원). 현역과 별개 조직.
- 사업계획서: 월 / 사업명 / 주관위원장 / 일정(예정일) / "지구 및 특우회" 행사 구분. 월별 일정표: 일/요일/내용/비고.

### 10.5 정관 구조
- 현역 정관: 제1장 총칙 ~ 제10장 해산 (총칙·회원·총회·임원·운영협의회·이사회 및 상무위원회·분과위원회·사무국·재정·해산), `제N조 (조 제목)` 약 134개, 본문에 `①②…`(항)과 `1. 2.`(호) 계층. **부칙**: 시행일 목록 12건(1979~2016) + **경과규정**(전역 선택·유예 등). 제정·개정 이력은 별도 표가 아니라 부칙의 "OOOO년 O월 O일부터 시행" 나열 → 개정 이력은 `시행일` 레코드로 모델링.
- 부속규정(같은 파일에 연속 수록, 각자 장·조 구조와 부칙 시행일 보유): 선거관리규정(9장), 회계규정(3장), 포상규정, 해외여행선발규정, 경조규정, 장학위원회규정(3장), 회관건립기금관리규정(4장).
- 특우회 정관: 제1~5장(총칙·회원·회의·임원·재정 및 기타) 약 51개 조 + 경조규정 + 선거관리규정.
- 텍스트 추출은 깨진 문자 없음(0건)이나 자동 추출 결과이므로 게시 전 원본 대조 필수(확정 방침). 조 번호 중복·누락은 검수 단계에서 확인.
- 수첩 정관(2016.1.27 시행)을 현행 정관으로 표시하지 않는다. "만 45세 전역" 규정이 있으나 앱은 자동 전환하지 않음(확정).
