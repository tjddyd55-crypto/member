# 관리자 기능 대조

기준은 최신 통합 브랜치다. PR 21·22·23을 각각 foundation에 넣지 않는다. foundation 병합은 Development API를 자동 배포하고 `npm run db:migrate:deploy`로 마이그레이션을 적용한다.

## 화면에서 하는 일

담당 관리자를 만들 때 모임과 권한을 고른다. 조회, 회원, 연락처, 운영이력, 이용권, 입금, 용량, 회원 제한, 설정이다. 연락처가 없으면 번호 대신 권한 없음을 보여 준다. 다른 슈퍼관리자도 비활성 버튼이 있다. 자기 계정과 이미 꺼진 계정은 버튼이 없다. 마지막 한 명은 서버가 거절한다. 이용권 ID는 이용권 탭에 보이고, 입금 연결 칸에 미리 들어간다. 입금 기록 실패는 빈 성공처럼 보이지 않고 서버 메시지를 보여 준다.

## 브라우저 22단계

명령은 `npm run build -w @member/gathering-admin` 뒤에 `npm run e2e -w @member/gathering-admin` 이다. Playwright Chromium이 프로덕션 빌드와 로컬 API를 붙였다. 뷰포트는 1280×800과 390×844이다. 둘 다 통과했다. 저장은 로컬 개발 파일함만 썼고 Development와 Production 데이터에는 쓰지 않았다.

| 단계 | 결과 |
| --- | --- |
| 1. 가입 | 회원 앱 화면은 열지 않음. 브라우저 테스트가 로컬 API로 계정을 만들어 관리 화면에 넘김 |
| 2. 모임 만들기 | 회원 앱 화면은 열지 않음. 만든 모임이 관리 목록에 보임 |
| 3. 30일 체험 | 브라우저에 `TRIAL`과 30일 뒤 만료 시각이 보임 |
| 4. 관리 목록 | 브라우저에서 바로 보임 |
| 5. 연락처 | 전화·문자 링크와 복사 버튼이 보임. 복사 클릭은 하지 않음 |
| 6. 정식 1년 | 브라우저에서 승인 뒤 출처가 `PAID`. 만료가 현재 잔여를 보존하는 계산은 API |
| 7. 사진 업로드 | 비회원 업로드 페이지에서 JPEG를 넣고 확정함. 회원 앱 카메라·앨범은 열지 않음 |
| 8. 50GB | 목록에 `50000000000` |
| 9. 100GB | 화면에서 바꾼 뒤 `100000000000` |
| 10. 축소 후 파일 유지 | 1000바이트로 줄인 뒤에도 올린 파일 1장 |
| 11. 정지 후 새 쓰기 | 화면에서 정지. 행사 생성 409 `SUSPENDED`. 업로드 페이지도 정지 문구 |
| 12. 기존 자료 | 정지·만료 중 다운로드 API 200. 회원 앱 앨범 화면은 열지 않음 |
| 13. 정지 해제 | 화면에서 해제 뒤 행사 생성 200 |
| 14. 체험 만료 | 30일 길이는 확인. 만료 뒤 쓰기 거절은 API. 만료 배지를 화면에서 다시 열지는 않음 |
| 15. 정식 만료 | 정식 행을 만든 뒤 만료시켜 쓰기 409 `ENTITLEMENT_REQUIRED`, 다운로드 200. 배지 재확인은 하지 않음 |
| 16. 인계로 회장 변경 | 지명까지만 함. 수락·확정으로 회장이 바뀌는 화면은 하지 않음 |
| 17. 최초 생성자 | 제한 뒤에도 생성자 이름과 `createdByUserId` 유지 |
| 18. 감사 화면 | `ADMIN_SUBSCRIPTION_APPROVE`가 보임 |
| 19. 회원 토큰 | 관리 API 401. 별도 화면은 없음 |
| 20. 무상과 금액 불일치 | 1,000원 연결은 거절 문구. 무상 승인 뒤 출처 `COMPLIMENTARY` |
| 21. 회원 제한과 인계 | 회장도 제한. 본인 모임 조회 403. 인계 행과 생성자 표시는 남음 |
| 22. 로그아웃·비밀번호·세션 | 브라우저에서 로그아웃과 비밀번호 변경. 이전 세션 401. 12시간 자연 만료는 기다리지 않음 |

회원 앱에서 아직 열지 않은 것은 1, 2, 7의 카메라, 12의 앨범, 16의 인계 완료다. 14·15의 만료 배지와 22의 12시간 대기도 화면으로 다시 보지 않았다. 그 절차는 `18-admin-browser-runbook.md`에 있다.

## 조회는 남고 새 쓰기만 막힘

만료와 정지를 각각 걸고 아래를 모두 409로 확인했다. 만료 코드는 `ENTITLEMENT_REQUIRED`, 정지 코드는 `SUSPENDED`다.

새 행사, 행사 수정, 회비, 장부 생성·수정·삭제, 행사·폴더 사진 예약·확정·재개, 영수증 예약·확정, 비회원 예약·확정.

같은 상태에서 모임, 행사, 사진 목록, 사진 다운로드, 앨범, 영수증 목록, 영수증 다운로드, 장부 목록, 재무 요약, 이용권, 인계 조회, 용량 조회는 200이다. 예전 회비 3만 원 행, 생성자, 인계 지명 행은 그대로다. 참석 변경, 역할, 초대, 폴더 이름, 링크 일시정지처럼 위 목록에 없는 쓰기는 이 게이트 밖에 있다.
