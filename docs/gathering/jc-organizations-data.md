## 규칙
- CONFIRMED: 한국JC 지방JC 현황 표에 인준번호와 함께 있고, 대조한 지구 공식 자료와 충돌하지 않음.
- NEEDS_REVIEW: 지구 공식 자료에만 있거나, 한국JC 표에는 있지만 현행 지구 자료와 맞지 않는 항목. DB에는 넣되 회원 선택 목록에는 나오지 않고 관리자 「검토 필요」에 표시됨.
- 고유 ID(registryKey): 지구 `D01`~`D16`(인준번호 앞 두 자리 순서), 로컬 = 인준번호(예 `01-242`), 검토 항목 `REVIEW-<지구>-<이름>`. DB 조직 ID(cuid)는 생성 후 바뀌지 않음.
- 공식 명칭: 표의 LOM 이름 + 「청년회의소」(서울지구 사이트의 `서울광진청년회의소` 표기 등과 같은 규칙), 표시 명칭: LOM 이름 + 「JC」. 원래 표기(LOM 이름, ~JC, ~청년회의소)는 별칭으로 저장.
- 예시 조직(서울광진, 강릉, 수원 등)은 예시라서가 아니라 한국JC 표에 있어서 들어감.
